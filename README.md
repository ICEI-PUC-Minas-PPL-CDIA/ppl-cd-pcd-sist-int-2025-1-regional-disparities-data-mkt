# Diferenças Regionais no mercado de Dados no Brasil

O objetivo deste projeto é desenvolver um sistema inteligente que analisa as disparidades no mercado de trabalho na área de dados no Brasil, com foco nas diferenças regionais. O sistema utilizará técnicas de análise de dados e aprendizado de máquina para identificar e mapear as desigualdades na distribuição de profissionais de dados, como cientistas de dados, engenheiros de dados e analistas, ao longo das diferentes regiões do país. A partir disso, o sistema irá gerar relatórios e visualizações interativas que mostram as variações salariais, a demanda por talentos e a oferta de profissionais qualificados, permitindo a compreensão das diferenças entre as regiões.

Este produto tem como objetivo fornecer uma ferramenta que ajude empresas, organizações governamentais e profissionais da área de dados a entender as dinâmicas do mercado de trabalho em termos geográficos, de maneira acessível e acionável. Além disso, o sistema será capaz de identificar padrões de escassez e saturação de talentos, o que pode influenciar decisões estratégicas em recrutamento e políticas públicas voltadas ao fomento de profissionais de dados no Brasil.
